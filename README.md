# Data Visualization: Work From Home Analysis

## Project Overview

This project explores work-from-home trends across U.S. counties in 2015 using Tableau. The analysis examines geographic patterns in remote work and the relationship between income and working from home.

## Objectives

- Explore differences in work-from-home rates across U.S. counties.
- Identify geographic patterns in remote work.
- Examine the relationship between income and working from home.
- Present findings through data visualization.

## Tools

- Tableau
- Data visualization
- Exploratory data analysis
